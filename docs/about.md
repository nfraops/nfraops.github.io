# About NFRAOPS

NFRAOPS is dedicated to building and maintaining infrastructure documentation and operational excellence.

## Mission

To provide comprehensive, accessible documentation for infrastructure operations and architecture decisions.

## Technology Stack

This site is built with:

- **MkDocs**: Static site generator
- **Material for MkDocs**: Documentation theme
- **Poetry**: Python dependency management
- **PlantUML**: Diagram generation
- **GitHub Pages**: Hosting platform

## Contributing

Documentation is a collaborative effort. Contributions are welcome through:

1. Forking the repository
2. Creating a feature branch
3. Submitting a pull request
